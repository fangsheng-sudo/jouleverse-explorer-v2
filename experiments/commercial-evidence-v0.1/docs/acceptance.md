# Jouleverse 可信商业事件接入与证据核验试点 V0.1 验收记录

日期：2026-11-12。状态：本地可审查试点，非生产上线。

## 实际交付

1. 商业证据私有envelope、固定元组摘要及公开事件ABI草案；更正/撤销保留历史，绑定网络与部署域。
2. Jouleverse薄配置：链编号3666、主线公开历史检查点；商业合约地址、代码哈希、起始区块与应用ID全部必须配置。
3. 严格只读回执核验：网络/代码/回执/日志/应用/摘要/区块/确认深度及固定链头复检；结果限定inclusion-only。
4. 有界索引：每轮8块、256条返回日志上限、32个区块哈希、2048条事件、原子推进、窗口内重组回退、超窗明确拒绝、可信快照恢复。
5. RPC资源保护：只读方法、64请求预算、8秒总超时、两operation/两原始请求并发上限、取消后真实完成才释放槽位、HTTP响应限1MiB、失败关闭流、错误脱敏。
6. 模拟创建/更正/撤销、真实loopback HTTP集成及可选企业底座桥接示例。企业底座仍保存企业数据，本包处理摘要及链事件。

## 主网只读观察

仅执行一次5方法batch：chainId、head、genesis block、公开检查点block、gasPrice；未扫描日志或发送交易。链编号3666与检查点匹配，完整精简观察见network-observation.json。创世哈希只记录为RPC观察，不擅自升级为官方可信锚；gasPrice不是最终费用报价。没有商业合约登记，因此未做真实商业锚定核验。

## 更换模型独立复审

开发：主任务Codex；复审：独立代理，编排配置gpt-6-astra。复审先发现3项实际问题：HTTP错误响应流存活、脱离operation的请求槽位/生命周期、链头回退沿用旧确认数。全部修复并由独立反例和35项测试复核。最终六个实现文件的SHA256见independent-review.md；复审代理未修改实现。

- 可信快照需要外部来源认证/完整性保护；索引没有数据库持久化、多进程调度、公共托管服务或SLA。
