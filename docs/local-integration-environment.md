# 第 5 项：本地只读接入测试环境

在开发者接入套件的工作区安装锁定依赖后，运行：

```sh
npx --no-install vitest run tests/local-integration-environment.spec.ts
```

测试在本机回环地址自动启动模拟节点，使用操作系统分配的临时端口，并在结束时关闭。通过真实 HTTP（网页传输协议）与 JSON-RPC（远程调用接口）路径检查合约部署核验，覆盖目录零请求、正确的地址与区块参数、错链拦截、代码不一致、无代码、节点异常及拒绝发送交易。

测试服务只提供显式白名单内的方法，不转发请求，不持有私钥，不联网访问真实节点。测试中的网络编号和地址来自目录，代码及区块响应是固定样例；它不是实际链，也不提供钱包、签名或写操作验收。若要增加回执测试，在支持模块中为对应白名单方法提供受控样例，再接入现有回执适配器；当前未做实际回执适配器的联调。

仓库全量检查：`npm test`、`npm run build`。公开测试网的节点、资源、合约和运行规则尚需链方确认。
