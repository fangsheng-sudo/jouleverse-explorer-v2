# 合约部署档案与代码核验

依赖 #66 的合约目录。目录打开及展开档案不联网；点击「只读核验链上代码」才向配置节点查询网络编号、区块高度、指定地址在该高度的运行时代码。单次最多三次只读请求，无重试、钱包签名或交易。

初始基线由配置节点 https://rpc.jnsdao.com 在网络编号 3666、区块 8584399（十六进制 0x82fccf）返回的字节码生成。采集前后该高度区块哈希一致。区块哈希和三份 Keccak-256（代码摘要）记录在部署核验模块，适用于 WJ、JNSVote 和创世金库多签。维护时用 eth_getBlockByNumber（按高度查询区块）复核基线区块，并用 eth_getCode（查询合约代码）在同一高度复算。

观测基线仅供检测代码变化。相同网络编号不能独立证明链身份；匹配摘要不证明源码、审计、权限、代理实现、可用性或业务安全。未取得可信证明前，源码版本、部署交易、管理和升级权限、停用状态均标记为未核实；其他地址读取代码后也不会显示匹配。
