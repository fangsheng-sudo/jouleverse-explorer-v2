# 功能称谓与配套介绍 V1.1

## 正式名称

**链上交易核验与记录导出工具**

## 配套介绍（可直接复制）

> 核对链上交易记录的一致性，导出可供人工、业务系统和智能体复用的查询结果。

## 统一用语

| 使用位置 | 统一称谓 |
|---|---|
| 功能正式名称、交接文档、路线图 | 链上交易核验与记录导出工具 |
| 页面标题、工具入口卡片 | 交易核验与导出 |
| 开发文档中的核心模块 | 交易与回执一致性核验模块 |
| 导出结果 | 链上交易观察记录 |

## 名称的能力边界

目前基于单一节点的返回数据，检查网络、交易、回执及区块记录的一致性，导出本次观察结果。

不称“交易证明”“可信凭证”或“支付验证器”，因为没有独立验证链上包含性，也没有核对具体付款或商业履约。交易顶层执行成功不能直接等同于付款成功或订单履约成功。
